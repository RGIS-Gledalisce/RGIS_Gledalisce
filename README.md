
# 🎭 Gledališče Lipa

### O projektu

**Gledališče Lipa** je projekt razvoja zalednega informacijskega sistema (REST API) za manjše mestno gledališče.

Sistem je namenjen upravljanju gledaliških predstav, sporeda, uporabniških računov ter rezervacij in nakupov vstopnic.

### Glavne funkcionalnosti

- **Spored in predstave** – pregled predstav, terminov in razpoložljivih mest.
- **Uporabniški računi** – registracija, prijava in upravljanje profilov.
- **Nakup vstopnic** – izbira sedežev, rezervacija in simulacija nakupa.
- **Administracija** – upravljanje predstav, terminov, cen in pregled statistike prodaje.

### Tehnologije

- C# / ASP.NET Core 10
- REST API
- Docker
- GitHub Actions
- Microsoft Azure
